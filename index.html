BUSINESS PLAN · SAAS IA ASSURANCE

Construire un SaaS B2B d’automatisation IA
pour les courtiers d’assurance

Une stratégie ultra-lean avec une équipe de 3 associés et des IA pour valider en France, puis étendre à la Belgique et au Luxembourg. Objectif : 3-5 M€ d’ARR en 15-20 ans pour un exit à 20-40 M€.

10–30 € budget technique mensuel MVP
< 500 € objectif de dépense à 90 jours
1 000 €/mois objectif moyen par client
3–5 M€ ARR cible à long terme

👥 Rôles & Compétences de l’Équipe

🎯 Associé 1 : Métier / CEO

Profil : Gestionnaire vie groupe en assurance (Luxembourg)

Rôle : Validation marché, vente, relation client.

Compétences clés :

  • Connaissance des courtiers et de leurs douleurs (KYC, LCB-FT, paperasse).
  • Réseau professionnel dans l’assurance.
  • Expérience en conformité (ACPR, CSSF).

Outils IA : Claude (rédaction emails, analyse retours clients).

📊 Associé 2 : Ops / COO

Profil : Comptable assistant

Rôle : Automatisation des processus, gestion administrative.

Compétences clés :

  • Gestion comptable et administrative.
  • Rigueur et organisation.
  • Capacité à documenter les processus.

Outils IA : n8n (workflows), Python (scripts d’automatisation).

🤖 Associé 3 : IT / CTO

Profil : Diplômé en informatique + connaissances en robotique

Rôle : Orchestration des IA, développement du produit.

Compétences clés :

  • Maîtrise des outils de développement (Next.js, FastAPI, Supabase).
  • Expérience avec les LLM (Claude, Mistral, Ollama).
  • Capacité à diriger une équipe d’IA (prompt engineering).

Outils IA : Claude Code, Cursor, Ollama.

✅ Pourquoi cette équipe est parfaite ?

Vos profils couvrent tous les besoins : métier (Associé 1), ops (Associé 2), et technique (Associé 3). Le seul défi est psychologique : accepter que l’IA fasse 80% du travail.

🚀 Étapes Immédiates (À Faire Cette Semaine)

📅 Timeline des 90 Premiers Jours

Semaines 1-2 : Validation du Marché

Associé 1 : Contacter 20 courtiers français via LinkedIn (utiliser un script généré par Claude).

Objectif : Obtenir 5 appels découverte → 3 "oui" pour tester le MVP.

Coût : 0 €

Semaines 3-4 : Prototypage du MVP

Associé 3 : Développer le MVP "Relance KYC" avec Claude Code + Supabase.

Fonctionnalités : Upload de documents, classification automatique, extraction des données, génération de relances.

Coût : 0-20 € (crédits API IA).

Semaines 5-6 : Pilote Gratuit

Associé 1 : Trouver 1 courtier pour tester le MVP gratuitement en échange de feedback.

Associé 2 : Documenter les processus et automatiser les ops (n8n).

Coût : 0 €

Semaines 7-8 : Itération & 1er Client Payant

Associé 3 : Itérer sur le MVP en fonction des retours.

Associé 1 : Signer le 1er client payant (500-1 000 €/mois).

Coût : 0 €

Semaines 9-12 : Scaling Initial

Associé 1 : Signer 2-3 clients supplémentaires.

Associé 3 : Ajouter des fonctionnalités (ex: gestion des avenants).

Coût : 20-50 €/mois (API IA, hébergement).

⚠️ Règle d’Or :

Ne pas coder avant d’avoir 3 "oui" verbaux de courtiers français. C’est la clé pour éviter de gaspiller du temps et de l’argent sur un produit que personne ne veut.

Outils : Claude Code, Ollama, GitHub, Vercel, Supabase.

⚠️ Risques & Solutions

Risque Impact Solution Responsable
Biais Luxembourg
Vouloir cibler le Luxembourg trop tôt.		 Perte de temps/marché. Cycles de vente longs. Règle stricte : Pas de développement pour le Luxembourg avant 10 clients français. Associé 1
Sur-ingénierie
L’Associé IT veut tout coder manuellement.		 Lenteur, coûts élevés, pas scalable. Règle : 80% du code généré par IA. Revue humaine uniquement pour la logique métier. Associé 3
Manque de clients
Difficulté à signer les 3 premiers clients.		 Échec du projet avant même de commencer. Solution : Pivoter sur un autre workflow (ex: gestion des avenants) ou un autre marché (Belgique). Associé 1
Dépendance aux API IA
Coûts qui explosent avec l’usage.		 Budget technique insoutenable. Architecture : Modèles locaux (Ollama) pour 70% des tâches. API payantes uniquement pour les tâches critiques. Associé 3
Conformité française
ACPR/ORIAS plus complexe que prévu.		 Amende ou rejet par les courtiers. Solution : Travailler avec un avocat français freelance (1 000-2 000 €/an). Associé 2
Bottleneck technique
L’Associé IT est le seul à comprendre le code.		 Projet bloqué si l’Associé IT tombe malade. Solution : Documenter tout avec l’IA (runbooks, architecture decisions). Associé 3
Concurrence
Autres SaaS ou agences proposent des solutions similaires.		 Difficulté à se différencier. Solution : Miser sur la spécialisation (courtiers français) et le prix (10-30 €/mois vs. 500-1 000 € pour les concurrents). Associé 1
🚨 Risques Critiques à Éviter Absolument
  1. Ne pas valider le marché avant de coder. C’est la cause n°1 d’échec des startups.
  2. Ne pas sous-estimer la conformité. Un problème avec l’ACPR peut tuer le projet.
  3. Ne pas dépendre d’un seul associé. Chaque rôle doit être redondant.
